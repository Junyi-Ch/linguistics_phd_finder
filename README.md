# Linguistics PhD Program Explorer

Find US Linguistics PhD programs, and the computational, applied, language-department and speech-science units around them, whose faculty match your research. Matching runs in the browser (Transformers.js + `snowflake-arctic-embed-m-v1.5`, BM25, a MiniLM re-ranker); the site is static and deployed to GitHub Pages.

Live: https://junyu-jiang0508.github.io/linguistics_phd/ (after the first deploy)

Sister site of the [Communication PhD Explorer](https://junyu-jiang0508.github.io/communication_phd/), and built from the same code.

## Layout

```
pipeline/            Python data pipeline (fetch helper, schemas, validators, build.py, taxonomy.json, hints.json)
  WORKFLOWS.md       the discover → scrape → label agent instructions and scope rules
  eval/              matcher test set, rubric and scripts
data/                programs_seed.json → programs_discovered.json → programs.json; labels/<slug>.json
  raw/               symlink → ~/data/linguistics_phd/data/raw (scraped records incl. profile text; not in git)
  cache/             symlink → ~/data/linguistics_phd/data/cache (fetched HTML, audits; not in git)
src/                 Astro 5 site (no framework islands; vanilla TS)
  data/              generated by pipeline/build.py (programs, faculty, taxonomy, meta)
  lib/               match.ts (embeddings + BM25 + hints), ui.ts, i18n.ts, shortlist.ts, site.ts (name, owner, repo)
  pages/             index (Match), programs/, faculty/, shortlist, about
public/search/       manifest.json, index.json, vectors.i8.bin (int8 faculty embeddings)
public/schools/      favicons · public/fonts/ self-hosted type (no faculty photos are published)
docs/                PLAN.md, design-brief.md, DATA_REPORT.md
```

## What differs from the Communication explorer

- **Taxonomy** (`pipeline/taxonomy.json`): five dimensions with the same keys, redefined — Subfields (21), Methods (14), Data (12), Populations (11), Languages (14), in English and Chinese.
- **Unit fields**: every unit and person carries `LING`, `COMP`, `APPLIED`, `LANG` or `SPEECH`, filterable on the Match and Directory pages, so core Linguistics departments and adjacent units are never mixed up.
- **Query detectors** live in `pipeline/hints.json`, read by both the browser and the eval harness.
- **Glossary** (`pipeline/glossary_zh.json`): Chinese linguistic terms and language names.
- **Probes and test set** rewritten for Linguistics; the matcher has not yet been re-evaluated (see `pipeline/eval/README.md`).

## Commands

```bash
npm install && npm run dev        # local site at localhost:4321/linguistics_phd/
npm run build                     # static output in dist/

# data pipeline (conda env "nlp": sentence-transformers, playwright, Pillow, bs4)
python pipeline/validate_raw.py data/raw/*.json
python pipeline/validate_labels.py data/labels/*.json
python pipeline/build.py          # → src/data, public/search, public/schools (profile text → vectors only)
```

Deploy: push to `main`; `.github/workflows/deploy.yml` builds and publishes to GitHub Pages (enable Pages → "GitHub Actions" in the repo settings once).
